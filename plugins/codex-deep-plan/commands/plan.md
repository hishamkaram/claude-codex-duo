argument-hint: '<issues | pr N | comment-url | "request text" | --request-file f>... [--slug <name>] [--rounds <1-3>] [--deep] [--solo] [--no-plan-mode] [--via codex|ccr:<alias>] [--implement ccr:<alias>]'

Use the deep-plan-duo skill for: $ARGUMENTS
Inputs may be any mix of issue numbers or URLs, PR numbers or URLs, single comment URLs, quoted request text, or --request-file paths. A question gets an answer, a content correction gets a short plan, a multi-issue root-cause hunt gets full depth (--deep forces it). "One PR" is a hypothesis to test, not a constraint. No file outside the artifact directory may be written, except the plan file plan mode asks for at the Phase 8 handoff. `--via codex|ccr:<alias>` picks the second model (default codex). `--implement ccr:<alias>` acts only after the plan is approved in plan mode: the skill then launches the separate write-capable implementer (`scripts/implement-run.sh`) on a new branch in a worktree and reports the branch; the planning run itself stays read-only.
